# Sistema de Monitoreo de Cultivos 🌱

Proyecto desarrollado en Python para registrar y supervisar
las condiciones ambientales de diferentes cultivos.

## Características

- Registro de cultivos.
- Registro manual de temperatura y humedad.
- Configuración de rangos ambientales.
- Generación de alertas cuando las mediciones están fuera de rango.
- Almacenamiento de información en Excel.
- Interfaz gráfica desarrollada con Tkinter.
- Visualización de estadísticas y gráficas.
- Consulta del historial de mediciones.

## Tecnologías utilizadas

- Python
- Tkinter
- OpenPyXL
- Microsoft Excel
- Git y GitHub

## Cómo ejecutar el proyecto

1. Descargar el repositorio.
2. Instalar Python.
3. Instalar las dependencias:

   pip install -r requirements.txt

4. Ejecutar el archivo:

   python main.py

## Modalidad

El sistema utiliza mediciones ingresadas manualmente
por el usuario.
